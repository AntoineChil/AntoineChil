## 🔬 Flagship project: biobank management (INSERM)

Web application built from scratch for a research lab, managing up to **600,000 biological samples**:

- 🗄️ Data model matching the physical storage structure (fridges, shelves, racks, drawers, boxes, positions) with Doctrine ORM
- 📥 Bulk CSV import, with dynamic column mapping and automatic creation of missing structures
- 🔍 Sample checkout module: real-time verification by barcode scan or manual entry, with highlighted matches
- ♻️ Cloning an existing fridge's structure to speed up setup
- 🖥️ CRUD interfaces in React, designed for daily use by lab staff

*Stack: Symfony · React · MariaDB · Doctrine ORM*
