## 🔬 Projet phare : gestion de biobanque (INSERM)

Application web développée de A à Z pour un laboratoire, gérant jusqu'à **600 000 échantillons biologiques** :

- 🗄️ Modélisation de la structure physique de stockage (frigos, étagères, racks, tiroirs, boîtes, positions) avec Doctrine ORM
- 📥 Import massif par fichier CSV, avec mapping dynamique des colonnes et création automatique des structures manquantes
- 🔍 Module de sortie d'échantillons : vérification en temps réel par scan ou saisie manuelle, surbrillance des correspondances
- ♻️ Clonage de la structure d'un frigo existant pour accélérer la configuration
- 🖥️ Interfaces CRUD en React, pensées pour un usage quotidien au labo

*Stack : Symfony · React · MariaDB · Doctrine ORM*

## 🔬 Flagship project: biobank management (INSERM)

Web application built from scratch for a research lab, managing up to **600,000 biological samples**:

- 🗄️ Data model matching the physical storage structure (fridges, shelves, racks, drawers, boxes, positions) with Doctrine ORM
- 📥 Bulk CSV import, with dynamic column mapping and automatic creation of missing structures
- 🔍 Sample checkout module: real-time verification by barcode scan or manual entry, with highlighted matches
- ♻️ Cloning an existing fridge's structure to speed up setup
- 🖥️ CRUD interfaces in React, designed for daily use by lab staff

*Stack: Symfony · React · MariaDB · Doctrine ORM*
